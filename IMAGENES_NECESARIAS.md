## 📐 Recomendaciones Generales

### Formato
- **Logos**: PNG con fondo transparente
- **Fotos**: JPG optimizado
- **Tamaño máximo**: 500KB por imagen

### Optimización
Antes de subir las imágenes, optimízalas con herramientas como:
- [TinyPNG](https://tinypng.com/) - Para PNG
- [Squoosh](https://squoosh.app/) - Para JPG y PNG
- [ImageOptim](https://imageoptim.com/) - Para Mac

### Aspectos Técnicos
- **Resolución mínima**: 72 DPI para web
- **Modo de color**: RGB
- **Nombres de archivo**: Sin espacios, minúsculas, con guiones

## 🎯 Prioridad

### Alta Prioridad (para launch)
1. Logo principal y versión blanca
2. Imagen hero principal
3. Fotos del equipo (al menos 4)
4. Logos de aliados principales (4-5)

### Media Prioridad
1. Imágenes de programas
2. Fotos restantes del equipo
3. Imágenes para heros de páginas internas

### Baja Prioridad
1. Imágenes decorativas adicionales
2. Placeholders personalizados

## 📝 Notas

- Las imágenes placeholder actuales mostrarán un error 404 hasta que se agreguen las imágenes reales
